# 0.3.33 — 3DAPlaceCandidates: пол без однозначного пола, мебель из кусков, метки опор

Только новый узел «3DA · постановка: кандидаты» и его модули (`candidates.py`, `candidates_cli.py`, раздел
`candidates` в `placement.yaml`):
- комната без однозначного пола: кандидаты выбирают самый большой кусок на уровне пола и ставят на него штатно
  (в своём процессе, свой ключ кэша) — раньше «auto profile floor is ambiguous» / «зона не определена для stand»;
- куски одной мебели (кровать/скамья, разрезанные корзинами высоты 2 см) — одна опора;
- метки опор: сиденье со спинкой — диван (даже маленький видимый кусок), длинный узкий верх — скамья/стол, тумба —
  только маленький почти квадратный верх; верх спинки — не опора;
- оценка: видимость = доля тела в кадре; ручной поворот относительно референса штрафуется;
- лимит одного кандидата 420 с; на мебельную опору — 2 ячейки зоны (опоры перебирают кандидаты).

Что не изменилось для manual: 3DAPlacePose и остальные узлы, их входы/выходы/поведение — без изменений.
Первый прогон после обновления пересчитает кэш постановки (в ключ входит `placement.yaml`) — результат тот же.
