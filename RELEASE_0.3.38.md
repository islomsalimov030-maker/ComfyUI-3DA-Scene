# 3DA 0.3.38 — разбор промпта в подсказку постановки

## Что нового
- Новый узел **3DAParseHint** «3DA · разбор промпта» (категория `3DA/auto`). Вход `text` — ответ текстовой модели, необязательный `prompt` — исходный промпт строки. Выходы: `hint_json` (STRING, `{"pose_class","support","facing","near_wall","prop"}` — тот же формат, что принимает `hint_json` у 3DAPlaceCandidates), `ok` (BOOLEAN), `note` (STRING).
  - JSON берётся из ответа модели, в том числе из ```-блока; поля проверяются: `pose_class` — из классов 3DA, `facing` — camera/away/side, `near_wall` — true/false; опора приводится к словам 3DA (`massage table` → `massage_table`, `weight bench` → `bench`, `exercise mat` → `mat`).
  - Ответ пустой, без JSON или с неверными полями — недостающие поля берутся из запасного разбора по ключевым словам исходного промпта, `ok=false`, причина в `note`. Узел не падает.
- **3DAAutoRow** «3DA · пакет: строка»: новый выход `hint_json` в конце списка — текст, сохранённый узлом «пакет: сохранить» в фазе 1 этой строки (пусто, если его нет). Старые выходы и их порядок не изменились.
- Модуль `auto/parse.py`, раздел `parse_hint` в `config/placement.yaml` (слова, синонимы, таблица ключевых слов), тесты `tests/test_parse_hint.py`.

## Что не изменилось для manual (AIO_manual_V3.0)
- Старые узлы `nodes.py`, их входы, выходы и значения по умолчанию не менялись (`check_compat`: OK).
- В `config/placement.yaml` добавлен раздел `parse_hint`. Файл входит в ключ кэша постановки, поэтому первый прогон 3DAPlacePose на каждой локации пересчитает постановку. Результат тот же; так же было в прошлых релизах с правкой этого файла.
