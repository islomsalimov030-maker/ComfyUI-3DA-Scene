# 3DA Scene 0.3.45

- Кэш кандидатов повторно использует рассчитанные варианты при смене `pick`. Изменения геометрии, карт глубины и поверхностей создают новый ключ кэша.
- Отчёт `3DAPlaceCandidates` передаёт для каждого отрендеренного кандидата измерения видимости и данные контакта. Их использует проверка выбора AUTO E6.
- Сигнатуры узлов совместимы с 0.3.44.
