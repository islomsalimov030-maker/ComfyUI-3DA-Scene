# 3DA Scene 0.3.44

Добавлен узел `3DAMaskBox` для построения прямоугольной мягкой маски по bbox силуэта, с JSON-координатами/долями кадра, рамочным preview и безопасным запасным прямоугольником. Новые вспомогательные узлы связывают выбор рассчитанного кандидата с его силуэтом.

Существующие узлы, их входы/выходы и поведение не менялись. Пакет `3DA/auto` подключает новые узлы; совместимость проверена `tools/check_compat.py`.
