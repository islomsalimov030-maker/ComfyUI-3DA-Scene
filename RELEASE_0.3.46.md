# 0.3.46 — исправления для художников

## Что исправлено
- **Прозрачные части персонажа/предмета в итоге** (волосы, одежда, края). Раньше вклейка подмешивала
  исходную комнату там, где MiniMax распускал фигуру за 3D-силу; теперь внутри фигуры и предмета
  итог — пиксели MiniMax, мягкий край — только узкой полосой (~3 px) по контуру. Если подключить маску
  человека (SAM3 «person») во вход «маска человека» узла вклейки — она становится жёстким ядром вклейки:
  волосы и одежда сохраняются целиком. «Чистые тени» больше не затирают волосы за силуэтом манекена.
- **Манекен после постановки съезжает вниз**: чистый сдвиг/поворот гизмо в 3D-окне теперь передаётся
  в рендер точно (проверено с точностью 0,0 см на тестовой сцене).

## Что делать художникам
Обновите пакет 3DA до 0.3.46 (Comfy Manager → обновить Custom Nodes) и обновите страницу (Ctrl+F5).

## Что не изменилось
Входы, выходы и настройки всех узлов прежние; воркфлоу AIO_manual_V3.0 обновлять не нужно.
Восстановление предмета (prop_repair) работает как раньше.
