# 0.3.18 — remote pad in the 3D window

- The unused axes helper in the bottom-left corner of the 3D window is replaced by a pad with three dots:
  red — right/left, green — up/down, blue — closer/farther (screen axes). Drag a dot to move, rotate or scale the
  selected object according to the current mode (scale is uniform). Useful when the object's gizmo arrows are
  outside the frame.
