# 0.3.34 — 3DAPlaceCandidates: посадка на опору, запасное «сиденье», опорные части на узкой зоне

Только новый узел «3DA · постановка: кандидаты» и его модуль `candidates.py` (раздел `candidates` в
`placement.yaml`):
- посадка: если тело встало над мебелью (wrong_surface/contact_fail, опорные части на 2–8 см выше верха), тот же
  кандидат проверяется ещё раз, опущенный штатным `body_dz` (постановка из кэша, без новой подгонки; проникновение
  и статус считает штатная проверка); не больше 2 раз на кандидата (`candidates.settle`);
- метка `seat`: маленький верх на высоте сиденья (≤ 0.60 м) — табурет/пуф/край скамьи, обрезанной кадром. Опора
  сидя только если другой мебели нет (`fallback_only`); тумба выше сиденья по-прежнему не опора;
- повтор «зона мягче» (видимый кусок сиденья меньше следа тела) теперь ещё и требует контакт только тех частей,
  что в `zone_relax_support_parts` (сидя — таз), а не бёдер над невидимой частью сиденья;
- комната без однозначного пола (кроме stand): куски на уровне пола (±8 см) — одна опора, как куски мебели;
- длинный узкий верх ниже сиденья (0.10–0.25 м) — скамья (спортивная), а не стол;
- лимит одного кандидата 600 с (= штатный 3DAPlacePose; 420 с обрывал скамью лёжа);
- в `candidates_json` у кандидата новые поля `support_parts`, `body_dz`.

Что не изменилось для manual: 3DAPlacePose и остальные узлы, их входы/выходы/поведение — без изменений.
Первый прогон после обновления пересчитает кэш постановки (в ключ входит `placement.yaml`) — результат тот же.
