# 3DA 0.3.37 — паспорт локации

## Что нового
- Новый узел **3DALocationPassport** «3DA · паспорт локации» (категория `3DA/auto`). Входы: `location`, `objects`, `plate` (выходы 3DA Location), необязательный `passport_id` (пусто — хэш картинки). Выходы: `passport` (JSON, схема 1), `preview` (локация с подписанными объектами: номер, тип, высота опоры в см, стрелка лицевой стороны), `needs_review` (true, пока паспорт не подтверждён).
- Паспорт считается один раз и лежит в `ComfyUI/user/default/3da/passports/<id>.json` (его же отдаёт `/api/userdata`). Есть файл той же картинки — узел берёт его без пересчёта. Человек проверяет `preview`, правит JSON (тип мебели, лишние объекты, `room_scale`) и ставит `"confirmed": true`. Подтверждённый файл не перезаписывается.
- **3DAPlaceCandidates**: новое необязательное гнездо `passport` (в конце, без виджета). С паспортом опоры, плоскости и `room_scale` берутся из него без пересчёта; запасной кандидат «пол» для сидя ставится, только если мебель не дала тела. Паспорт входит в ключ кэша кандидатов. Без гнезда — всё как раньше.
- Модуль `tools/scene3d/posev2/passport.py`, тесты `tests/test_passport.py`, раздел `passport` в `config/placement.yaml`.

## Что не изменилось для manual (AIO_manual_V3.0)
- Старые узлы, их входы, выходы и значения по умолчанию не менялись (`check_compat`: OK).
- В `config/placement.yaml` добавлен раздел `passport`. Файл входит в ключ кэша постановки, поэтому первый прогон 3DAPlacePose на каждой локации пересчитает постановку. Результат тот же; так же было в 0.3.31–0.3.34.
