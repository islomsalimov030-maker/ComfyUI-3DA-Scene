# 0.3.42 — исправление кадра и контакта recline

- Для `3DAPlaceCandidates` добавлены варианты сдвига по глубине камеры при слишком крупном/малом пиксельном силуэте; пороги и величины заданы в `config/placement.yaml`.
- Увеличен приоритет ожидаемого типа опоры и штрафов кадра в оценке кандидатов, чтобы не выбирать пол при наличии визуально корректной мебели.
- Если корпус recline далеко от опоры, создаются два варианта наклона тела; `body_dpitch`/`body_droll` теперь передаются штатному PlacePose только новым узлом кандидатов.
- Старые узлы, их входы/выходы и поведение при тех же входах не менялись.

Проверки и выпуск выполняются по протоколу `server-ops`; локальные тесты не заменяют регрессии до/после и полный паспортный замер.
