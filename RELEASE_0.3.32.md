# 0.3.32 — ручки позы: колено и локоть не выгибаются назад

- **3D-окно и 3DA Place Pose** (ключ `pose_edits`): у почти прямой руки/ноги (угол в суставе больше 170°,
  `config/pose_edits.yaml: straight_deg`) направление сгиба берётся по анатомии — колено к носку стопы, локоть
  назад-вниз. Колено, смотрящее назад (переразгибание), тоже сгибается вперёд. Раньше шум позы в пару миллиметров
  мог согнуть колено/локоть в обратную сторону. Согнутые суставы гнутся, как прежде.
- 3D-окно: предел сдвига ручки (0.8 м) — для итогового сдвига, а не для одного шага; веса для ручек строятся
  сразу после загрузки сцены (первое движение без задержки).

Не изменилось для manual: входы/выходы узлов, ключ кэша постановки, поведение без `pose_edits`.
